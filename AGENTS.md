## Обзор проекта

ViaTrade Telegram Bot — отдельный Python-сервис для привязки Telegram-аккаунтов ViaTrade и доставки уведомлений из Redis Streams. Детали назначения и ограничений находятся в `.ai-factory/DESCRIPTION.md`.

## Технологический стек

- **Язык:** Python 3.14.7+
- **Сборка и зависимости:** uv, `uv_build`
- **Telegram:** aiogram
- **Redis:** redis-py asyncio
- **HTTP и конфигурация:** httpx, pydantic-settings
- **База данных:** не выбрана
- **ORM:** не выбран

```text

│       ├── logging_config.py        # настройка стандартного logging

│       ├── integrations/            # клиенты внешних сервисов
│       │   └── backend_client.py    # internal HTTP API backend
│       └── notifications/           # Redis Streams и сценарии уведомлений
│           ├── consumer.py          # Consumer Group и обработка сообщений
│           ├── delivery.py          # нейтральный контракт доставки

│           ├── models.py            # валидация контрактов уведомлений
│           └── store.py             # операции Redis Streams и идемпотентность

```

## Правила для агентов

- Выполняйте составные команды Git отдельными шагами, чтобы каждый шаг можно было проверить.
  - Неправильно: `git checkout master && git pull`
  - Правильно: сначала `git checkout master`, затем (после настройки удалённого репозитория `origin`) `git pull origin master`.
- Не добавляйте токены, пароли и другие секреты в исходный код или репозиторий.
- После любого изменения Python-кода или конфигурации Ruff обязательно выполняйте `uv run ruff check --fix`, исправляйте все оставшиеся ошибки и предупреждения, затем повторяйте проверку до чистого результата.

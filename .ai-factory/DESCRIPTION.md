# ViaTrade Telegram Bot

## Обзор

Минимальный Python-проект Telegram-бота для ViaTrade. Сейчас он содержит только точку входа и пакетную заготовку; прикладные сценарии и интеграция с Telegram API ещё не реализованы.

## Ключевые возможности

- Запуск приложения через консольную команду `viatradetgbot`.
- Точка входа Python-пакета `viatradetgbot`.
- Основа для будущего Telegram-бота ViaTrade.

## Технологический стек

- **Язык:** Python 3.14.7+
- **Сборка и управление зависимостями:** uv и `uv_build`
- **Фреймворк:** не выбран
- **База данных:** не выбрана
- **ORM:** не выбран
- **Интеграции:** Telegram Bot API запланирован, но библиотека ещё не подключена

## Заметки по архитектуре

Пакет расположен по пути `src/viatradetgbot/` и запускается из `__main__.py`. Для небольшого бота выбрана слоистая архитектура: обработчики Telegram остаются тонкими, бизнес-логика располагается в сервисах, доступ к внешним системам изолируется в адаптерах и репозиториях.

## Нефункциональные требования

- **Логирование:** централизованное, с уровнем из `LOG_LEVEL` после добавления прикладной логики.
- **Обработка ошибок:** явные исключения и понятные сообщения для пользователя; ошибки внешних API не должны завершать процесс бота.
- **Безопасность:** токены и прочие секреты хранятся только в переменных окружения или защищённом хранилище.

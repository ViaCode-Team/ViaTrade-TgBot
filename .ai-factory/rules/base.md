# Базовые правила проекта

> Правила автоматически определены по текущему коду. Уточняйте их по мере развития проекта.

## Именование

- Файлы и модули: `snake_case`; имена пакетов — строчные.
- Переменные и функции: `snake_case`.
- Классы: пока отсутствуют; при появлении использовать `PascalCase` по стандарту Python.
- Константы: при появлении использовать `UPPER_SNAKE_CASE`.

## Структура модулей

- Исходный код находится в `src/` и использует layout `src`.
- Корневой пакет — `src/viatradetgbot/`.
- Telegram-специфичный код размещается в под-пакете `src/viatradetgbot/bot/`.
- Точка запуска — `src/viatradetgbot/__main__.py`; публичные экспорты — в `__init__.py`.

## Обработка ошибок

- Текущий код не содержит обработчиков ошибок. В новом коде обрабатывайте ожидаемые ошибки внешних сервисов на границе интеграции и передавайте доменные ошибки в слой обработчиков.

## Поток управления

- Предпочитайте плоский и читаемый поток управления вместо глубокой вложенности.
- Используйте guard clauses, ранние `return`/`continue`, небольшие именованные функции и явную классификацию ветвей, если это делает код понятнее.
- Обрабатывайте крайние случаи и нерелевантные ветви раньше, чтобы основной путь оставался заметным.

## Логирование

- Сейчас используется только `print()` в стартовой заготовке. При реализации бота замените его на стандартный модуль `logging` и настройку уровня через `LOG_LEVEL`.

# Исправление Pylance-диагностик для конфигурации и Redis

**Дата:** 2026-08-14 23:59
**Файлы:** `src/viatradetgbot/config.py`, `src/viatradetgbot/bot/application.py`, `src/viatradetgbot/bot/notification_consumer.py`, `pyrightconfig.json`
**Серьёзность:** low

## Проблема

Pylance сообщал о несовместимых строковых значениях по умолчанию для `HttpUrl` и `RedisDsn`, обязательных аргументах `BaseSettings` и не-awaitable результатах async Redis-клиента.

## Корневая причина

Pydantic корректно приводит строки во время runtime-валидации, но Pylance проверяет статические аннотации. Типы `redis-py` для части команд содержат объединение синхронного результата и awaitable, хотя клиент `redis.asyncio.Redis` возвращает awaitable во время работы.

## Решение

Значения по умолчанию создаются типизированными конструкторами, обязательные секреты по-прежнему валидируются пустым безопасным default factory, а фактические awaitable Redis уточнены через `cast`. Добавлен `pyrightconfig.json` с virtual environment, Python 3.14 и исключениями служебных каталогов.

## Предотвращение

- Запускайте `npx --yes pyright` вместе с `uv run ruff check --fix` после изменений аннотаций или интеграций.
- Для runtime-приведения Pydantic используйте типизированные default values, если Pylance проверяет присваивание в классе.
- При несоответствии generic-аннотаций внешней async-библиотеки уточняйте только реально awaitable результат вызова.
